# Source-code license status

**The author has not yet selected a root license for ScalLoc's own code.**

This repository-preparation step does not choose MIT, Apache-2.0, or another license on the author's behalf. There is intentionally no new blanket root `LICENSE` granting rights over the entire project. Preparing code for a public repository is not itself a license grant.

Before announcing an open-source release, the author should:

1. Choose the license for code they have the rights to license and add the appropriate root license text and copyright attribution.
2. Confirm the provenance and redistribution rights of adapted or contributed code.
3. Preserve every included upstream license and copyright notice, and make clear that those components remain under their own terms.
4. Publish separate terms and download information for Thermal-Oblique, satellite maps, DSMs, and any checkpoint redistribution.

Included third-party code is already accompanied by its existing licenses; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). VGGT uses its own license, MINIMA and embedded DINOv2 carry Apache-2.0 terms, and RoMa carries MIT terms for its own code. None of these establishes a root license for ScalLoc or automatically licenses all model weights.

Until the author completes the licensing decision, describe this directory as a **release preparation**, not as an already fully licensed open-source distribution. No publication authors, ownership claims, or citation records have been fabricated.
